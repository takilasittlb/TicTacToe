# TicTacToe
jeu de tic tac toe

🎮  Laboratoire Jeu de plateau : Phase 1 – Tic Tac Toe
Durée : 2 séances

🧠 Introduction
Le jeu de Tic Tac Toe est simple, bien connu et possède un espace de recherche limité.
Il constitue un excellent point de départ pour implémenter les algorithmes Minimax et Alpha‑Beta, notamment parce que :
• 	le débogage est plus simple ;
• 	l’arbre de recherche reste relativement petit ;
• 	il permet de comprendre les bases d’un agent intelligent pour un jeu à deux joueurs.
🎯 Objectifs du laboratoire
• 	Implémenter Minimax
• 	Implémenter Alpha‑Beta
• 	Comprendre l’architecture d’un agent intelligent
• 	Apprendre à déboguer un arbre de recherche
• 	Produire un agent qui ne perd jamais (au pire, match nul)
